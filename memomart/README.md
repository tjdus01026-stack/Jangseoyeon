# 🛒 MEMO MART · Groceries for Your Brain

메모를 상품으로 만들어 진열하고, 직접 가격을 매기고, 나중에 다시 평가하는 웹앱.
미국 시골 동네 할인마트 광고 전단 스타일. 빌드 도구 없이 HTML · CSS · JavaScript만으로 동작합니다.

## 실행 방법 (VS Code)

1. VS Code에서 `memo-mart` 폴더 열기
2. 추천 확장 **Live Server** 설치 (폴더를 열면 설치 안내가 뜹니다)
3. `index.html` 우클릭 → **Open with Live Server**

> `index.html`을 브라우저에서 바로 열어도 동작합니다. 서체(Google Fonts)는 인터넷 연결 시 적용됩니다.

## 사용 흐름 — 3단계

1. **Write it** — 사이트를 열면 바로 메모 입력칸에 커서가 있습니다. 첫 줄이 상품명, 나머지가 내용이 됩니다.
2. **Price it** — 가격 버튼을 누르거나 직접 입력합니다. 노란 가격표가 바로 바뀝니다.
3. **Put it on the shelf** — 버튼 또는 `Ctrl/⌘ + Enter`. 진열대 맨 앞에 상품이 떨어집니다.

진열된 상품을 **탭하면 카드가 뒤집히며 상세 화면**이 열립니다. 여기서 모든 것을 한 번에 합니다.
**확인 버튼이 없습니다 — 누르는 순간 저장됩니다.**

| 하고 싶은 것 | 방법 |
|---|---|
| 그림 그리기 | 메모 입력칸 옆 그림판에 그리기 (색 7가지 · 굵기 S/M/L · 지우개 · Undo · Clear). 글 없이 그림만 올려도 됨 → 그림이 상품 사진처럼 카드·상세 화면·전단지에 들어감 |
| 그림 다시 그리기 | 상세 화면에서 🖍 Redraw / Remove drawing |
| 별점 주기 | 별을 탭 → 즉시 저장 (다시 탭하면 수정) |
| 리뷰 남기기 | 입력 후 `Enter` (창을 닫아도 써둔 내용은 저장) |
| 가격 바꾸기 | ▲ ▼ 화살표 또는 금액 직접 입력 → 즉시 반영, 가격 변동 내역에 기록 |
| 제목·내용 고치기 | 텍스트를 탭해서 바로 수정 |
| 세트로 묶기 | 상세 화면에서 🛒 Add to cart (또는 ✋ 손잡이로 끌어 장바구니에 놓기) → 2개 이상이면 Make a Combo |
| 콤보에 메모 추가 | 진열대 상품을 ✋ 손잡이로 끌어 콤보 팩 위에 놓기 → 목록에 추가되고 콤보 가격도 그만큼 올라감 |
| 전단지 만들기 | 상세 화면 · 장바구니 · 콤보 팩에서 📰 Flyer → 이미지로 저장 |
| 잊고 있던 메모 꺼내기 | 🎲 Pull an old memo, 또는 Collecting Dust 탭 |
| 진열 순서 바꾸기 | ✋ 손잡이를 잡고 끌기 |

- 상품을 열어 볼 때마다 조회수가 올라가고, 가장 많이 읽은 메모가 **TOP SELLERS**에 오릅니다.
- 진열 코너(Ideas, To-Do, Study…)마다 포장 색이 정해져 있어 색만 봐도 종류를 알 수 있습니다.
- 장바구니 막대는 상품을 담았을 때만 화면 아래에 나타납니다.

## 폴더 구조

```
memo-mart/
├─ index.html        화면 뼈대 (간판, 메모 입력, 진열대, 순위표, 장바구니)
├─ css/style.css     할인마트 광고 스타일, 애니메이션
├─ js/firebase-config.js  공유 진열대 설정값 (Firebase)
├─ firestore.rules         Firebase 보안 규칙 (작성자만 수정·삭제)
├─ js/app.js         데이터 · 렌더링 · 인터랙션 · 전단지 생성
└─ .vscode/extensions.json
```

## 모두가 보는 공유 진열대 만들기 (Firebase, 무료)

설정 전에는 메모가 **각자의 브라우저에만** 저장됩니다. 아래를 한 번 해 두면 GitHub Pages 링크로 들어오는 모든 사람이 같은 진열대를 봅니다.

- 누구나 메모를 올릴 수 있고, **모든 메모와 리뷰는 모두에게 보입니다.**
- 메모의 제목·내용 수정, 가격 변경, 삭제는 **쓴 사람만** 할 수 있습니다. 콤보 팩은 **누구나** 가격 변경·메모 추가·풀기가 가능합니다. (Firebase 보안 규칙으로 서버에서도 막힘)
- 다른 사람 메모에는 별점·리뷰만 남길 수 있고, 리뷰 삭제는 리뷰를 쓴 사람만 가능합니다.
- 장바구니와 진열 순서(드래그)는 각자의 브라우저에만 저장됩니다.

### 1. Firebase 프로젝트 만들기
1. https://console.firebase.google.com 에 구글 계정으로 로그인 → **프로젝트 추가** (이름 예: `memo-mart`, 애널리틱스는 꺼도 됨)
2. 왼쪽 메뉴 **빌드 → Authentication → 시작하기 → 로그인 방법 → 익명(Anonymous)** 사용 설정
3. Authentication → **설정 → 승인된 도메인**에 `내아이디.github.io` 추가
4. **빌드 → Firestore Database → 데이터베이스 만들기** → 위치 `asia-northeast3 (서울)` → **프로덕션 모드**

### 2. 보안 규칙 넣기
Firestore Database → **규칙** 탭에 이 저장소의 `firestore.rules` 내용을 전부 붙여넣고 **게시**.

### 3. 설정값 붙여넣기
1. 프로젝트 개요 옆 ⚙️ → **프로젝트 설정 → 내 앱 → 웹(</>)** 앱 추가 (호스팅 체크 안 해도 됨)
2. 나오는 `firebaseConfig = { ... }` 안의 값을 `js/firebase-config.js`에 그대로 붙여넣기
3. GitHub에 커밋·푸시 → 1~2분 뒤 링크에서 확인

> `apiKey` 등은 웹 앱용 공개 식별자라 GitHub에 올려도 괜찮습니다. 데이터 보호는 2번의 보안 규칙이 담당합니다.

**알아둘 점**
- "쓴 사람"은 브라우저 단위로 구분됩니다. 다른 기기·브라우저나 사이트 데이터를 지운 브라우저에서는 내 메모도 남의 메모처럼 수정할 수 없습니다.
- 그림은 메모와 함께 저장됩니다(메모 하나당 최대 약 1MB). 무료 요금제로 개인·소규모 사용에는 충분합니다.
- 설정 전 브라우저에 저장해 둔 메모는 공유 진열대로 자동으로 옮겨지지 않습니다.

## 데이터

Firebase를 설정하지 않으면 모든 데이터는 브라우저 `localStorage`(`memo-mart-v3` 키)에 저장되며, 가격은 센트 단위 정수로 저장됩니다.
초기화하려면 개발자 도구 콘솔에서:

```js
localStorage.removeItem('memo-mart-v3'); location.reload();
```
